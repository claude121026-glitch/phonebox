# phonebox

## Live chess championship page

`chess/index.html` shows the live board for the World Chess Championship (or any Lichess broadcast). It shows the board, players, clocks and moves, and updates every 10 seconds. The data comes from the free Lichess broadcast feed.

- **On a computer:** download `chess/index.html` and double-click it.
- **On a phone:** turn on GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/ (root)`), then open
  `https://claude121026-glitch.github.io/phonebox/chess/`
